## 다른 사이트와 검색 노출이 겹치지 않게 한 것

같은 사업자(드리움커튼블라인드)의 사이트가 4개(드리움 · 결앤빛 · 런던커튼 · 광명커튼)가 되므로, 서로 노출을 깎아 먹지 않도록 이렇게 만들었습니다.

1. **문장을 전부 새로 썼습니다.** 세 사이트의 모든 페이지와 자동으로 비교해서 **똑같은 문장 0개**를 확인했습니다.
   (페이지끼리 겹치는 비율도 최대 11% — 메뉴 이름 · 제품 이름 같은 공통 단어 수준)
2. **지역 페이지는 광명 + 바로 붙은 지역만** 만들었습니다. 드리움 · 결앤빛이 이미 서울 · 경기 전 지역 페이지를 갖고 있어서,
   광명커튼까지 "강남 커튼" 같은 페이지를 만들면 같은 사업자 사이트끼리 같은 검색어로 경쟁하게 됩니다.
   나머지 서울 · 경기 · 인천은 시공 지역 페이지에 "방문 가능" 글로만 적었습니다.
3. **사진도 다른 사이트와 겹치지 않게** 해 주세요. 같은 사진을 여러 사이트에 쓰면 네이버가 유사 문서로 볼 수 있습니다.
4. **디자인 색 · 글꼴 · 로고도 다르게** 했습니다. (딥 그린 + 햇살 앰버, 고운바탕 글꼴)

앞으로 글을 추가할 때도 다른 사이트 글을 복사하지 말고 새로 써 주세요.

## 광명 검색 강화 — 이렇게 되어 있습니다

- 메인 제목 · 설명에 "광명 커튼 · 블라인드"를 가장 앞에, 철산 · 하안 · 소하 · 광명뉴타운 · 광명역을 함께
- 광명을 **동네 단위 7개 페이지**로 나눠 "철산 커튼", "하안동 블라인드", "소하동 커튼", "광명뉴타운 커튼", "광명역 커튼" 같은 검색어를 각각 노림
- 동네마다 실제 사정(하안주공 같은 구축 단지, 뉴타운 입주, 광명역 고층 통창, 학온동 주택)에 맞는 다른 글 + 지역 FAQ(구조화 데이터)
- 매거진 글도 광명 상황에 맞춤: 뉴타운 입주 준비, 하안 · 철산 구축 교체, 광명역 통창, 광명 업체 고르기
- 업체 구조화 데이터의 소재지 = **경기도 광명시**
- 메인에 광명 동네 바로가기와 전체 지역 링크를 HTML로 넣어 네이버 로봇이 바로 따라갈 수 있게 함

### 홈페이지 밖에서 노출을 늘리는 방법 (플레이스 없이)

사업자가 드리움 하나이고 플레이스가 이미 드리움으로 등록되어 있어서, 광명커튼은 **플레이스를 따로 만들지 않습니다.**
(같은 사업자로 플레이스나 구글 비즈니스 프로필을 하나 더 만들면 중복 등록으로 둘 다 불이익을 받을 수 있어요.)
대신 아래 방법으로 보완합니다.

1. **네이버 블로그 (가장 효과 큼)** — "광명커튼" 이름의 블로그를 만들고 광명 시공 후기를 올리기.
   제목에 "철산동 ○○아파트 거실 커튼", "하안주공 블라인드 교체"처럼 동네 + 제품을 넣고, 글 끝에 홈페이지 주소를 연결.
   블로그 주소는 `js/config.js` → `blogUrl` 에 넣어 두세요. 홈페이지 글과 똑같은 문장은 쓰지 말 것.
2. **드리움 플레이스 활용** — 드리움 플레이스의 업체 소개 · 키워드에 "광명 커튼 · 블라인드 시공"을 넣고,
   플레이스의 블로그 · SNS 칸에 광명커튼 블로그를 연결하면 광명 검색에서도 함께 보일 수 있어요.
   (드리움의 소재지가 광명이면 효과가 더 큽니다)
3. **당근 비즈프로필 · 숨고** — 광명 동네 기반이라 지역 고객과 바로 연결됩니다. 프로필에 홈페이지 주소 연결.
4. **네이버 서치어드바이저 · 구글 서치콘솔** — 아래 순서대로 등록하면 홈페이지 자체가 검색에 잡힙니다.

어디에 올리든 **상호(광명커튼) · 전화번호 · 홈페이지 주소를 똑같이** 적어 주세요.

## 검색엔진 등록 순서

1. **네이버 서치어드바이저** (searchadvisor.naver.com) → 사이트 등록 → HTML 태그 인증
   → 받은 `<meta name="naver-site-verification" ...>` 를 `_build/common.py` 의 인증 주석 자리에 넣고 다시 생성
   (또는 `index.html` 의 `<head>` 주석 자리에 바로 붙여넣기)
2. 서치어드바이저 → 요청 → **사이트맵 제출**: `https://도메인/sitemap.xml`
3. 서치어드바이저 → 요청 → **RSS 제출**: `https://도메인/rss.xml`
4. 서치어드바이저 → 요청 → **웹 페이지 수집**: `naver-index-urls.txt` 의 주소를 날짜별로 붙여넣기
5. **구글 서치콘솔**도 같은 방식으로 인증 + 사이트맵 제출

이미 들어 있는 것: 페이지별 title · description · keywords, canonical, OG(카톡 공유 미리보기 이미지),
구조화 데이터(업체 정보 · FAQ · 게시글 · 경로), sitemap.xml, rss.xml, robots.txt, https · www 통일(.htaccess), 모바일 대응.

## 시공사례 추가 (사진이 생기면)

1. 사진을 `images/cases/case-01.jpg` (대표), `case-01-2.jpg` (두 번째) … 로 넣기 (1600×1200 권장)
2. `_build/build.py` 의 `CASES = []` 안에 주석의 형식대로 한 덩어리 추가
   - `space` 에 **"광명 철산 · 34평 거실"** 처럼 동네와 평수를 적으면 지역 검색에 크게 도움이 됩니다.
3. `python3 _build/build.py` 실행

사례가 하나라도 생기면 메인에 사례 영역이 나타나고, 시공사례 페이지의 검색 제외가 풀리고, sitemap에도 자동으로 들어갑니다.

## 새 페이지 추가

`_build/` 의 데이터 파일을 고치고 `python3 _build/build.py` 실행
- 지역 추가: `_build/areas_data.py` 에 한 덩어리 추가 (소개 글은 지역마다 **다르게**, 다른 사이트 글 복사 금지)
- 매거진 글 추가: `_build/posts_data.py` 에 한 덩어리 추가
- 헤더 · 푸터 · 지역 목록(`js/includes.js`), sitemap, rss, 네이버 수집 목록이 자동으로 같이 갱신됩니다.
- 사진 자리표시: `python3 _build/placeholders.py` (이미 있는 사진은 건드리지 않음)
- 로고 다시 만들기: `python3 _build/logo.py 글꼴폴더` (Google Fonts 의 GowunBatang-Bold.ttf, Marcellus-Regular.ttf)
